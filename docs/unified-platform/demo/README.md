# Demo UI Images

Thư mục này dành riêng cho ảnh demo giao diện do chủ dự án tự tải lên GitHub.

## Quy tắc

- Ảnh trong thư mục này chỉ dùng để tham khảo thiết kế.
- `05_UI_UX_SPEC.md` vẫn là nguồn yêu cầu UI/UX chính thức.
- Không dùng dữ liệu mẫu trong ảnh làm dữ liệu production.
- Web, Android và iOS phải dùng dữ liệu Firebase thật.
- Tiếng Việt là ngôn ngữ chính; English là ngôn ngữ thứ hai.
